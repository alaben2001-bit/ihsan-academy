# أكاديمية الإحسان — Cloudflare Pages وD1

هذا هو مصدر نشر المنصة الداخلية. يعمل المشروع عبر Cloudflare Pages Functions وD1، ويُبنى من هذا المجلد.

## النشر

- مشروع Pages: `ihsan`
- فرع الإنتاج: `migration/cloudflare-student-platform`
- جذر البناء: `deploy/cloudflare`
- أمر البناء: `npm install && npm run prepare:assets`
- مجلد الإخراج: `public`
- عنوان Pages التقني الحالي: `https://a-ihsan.pages.dev`. لا تعتبره النطاق النهائي المعتمد للطلاب قبل اعتماد صاحب المشروع؛ المنصة داخلية ومستبعدة من الفهرسة.
- بوابة التيسير العامة منشورة بصورة مستقلة في مشروع `a-taysir` من الفرع `feat/taysir-public-portal` ومصدر `site-taysir/`.

## الوظائف الموجودة

- تسجيل الدخول وكلمات المرور والجلسات والصلاحيات حسب الدور والفوج.
- ربط حساب Google وتدفق التسجيل/استرداد الحساب عبر واجهات محكومة.
- ملفات الطلاب والأفواج والحضور.
- سجل القرآن اليومي وخطط الحفظ والتثبيت والورد.
- اعتماد الشيخ للحفظ الجديد والتثبيت: تقارير الطالب الجديدة تبقى معلّقة حتى القرار؛ الرفض يتطلب سببًا، والتصحيح لا يكرر السجل أو النقاط.
- سجل نقاط منفصل لنقاط الإنجاز ورصيد المتجر، مع دفتر حركات وتصحيح موثق.
- بطاقات الطالب وQR، المهام والشارات والترتيب، متجر مكافآت حقيقية، ومسابقات.
- النسخ الاحتياطي والاستعادة اليدوية مع التحقق من الصيغ والروابط والمعرفات.
- PWA قابلة للتثبيت؛ يخزّن Service Worker غلاف التطبيق والأصول الثابتة، ولا يخزّن استجابات API.

## قرارات تشغيلية ثابتة

- خطط القرآن السابقة نماذج تجريبية قيد المراجعة، وليست تكليفات نهائية.
- نظام المستويات والترقيات الرقمية مؤجل؛ الأوسمة والإنجازات باقية.
- لا تضف جوائز أو أسعارًا أو مخزونًا افتراضيًا.
- لا تجرِ تحويلًا تاريخيًا للأرصدة أو إعادة احتساب للنقاط دون خطة مستقلة واختبار استعادة.
- لا تنشئ أو تحذف حسابات اختبار في قاعدة الإنتاج.
- التوسعة الحالية لمخطط اعتماد القرآن وأعمدة مراجعة نتائج المسابقات إضافية وغير هدّامة، وتُنفّذ بصورة idempotent عند تهيئة مخطط API. لا تغيّر ملفات الترحيلات المطبقة؛ أضف ترحيلًا جديدًا عند الحاجة.

## الاختبار

شغّل من هذا المجلد:

```bash
npm install
npm run check
npm run prepare:assets
npx wrangler deploy --dry-run
```

اختبارات CI تتضمن مسارات الطالب والمتجر والنقاط، اعتماد القرآن والرفض والتصحيح، النسخ والاستعادة، الصلاحيات، المسابقات، الهاتف، QR والمهام والتسجيل. نجاحها لا يغني عن اختبار حي بحسابات معتمدة، ولا يثبت إعداد Google Console أو فهرسة الموقع أو التثبيت على جهاز فعلي.

## ملفات مهمة

| المسار | الوظيفة |
|---|---|
| `src/index.js` | API والمصادقة والصلاحيات وD1 |
| `site/app.js` | واجهة المنصة |
| `site/style.css` | التصميم المتجاوب |
| `site/index.html` | نقطة دخول المنصة |
| `site/manifest.json` | تعريف PWA |
| `site/service-worker.js` | التخزين المؤقت وتحديث التطبيق |
| `migrations/` | ترحيلات D1 |
| `scripts/security-check.mjs` | اختبارات الحماية والانحدار |
| `scripts/prepare-assets.mjs` | تجهيز ملفات النشر |

## حماية البيانات

1. احتفظ بنسخة احتياطية محمية، واختبر الاستعادة قبل أي تغيير في المخطط أو نقل.
2. لا تحذف سجلات الطلاب أو نقاطهم أو بطاقاتهم أو سجلات القرآن أثناء تنظيف الملفات.
3. لا تستخدم إجراء تهيئة الحسابات الجماعي لتجديد كلمات المرور.
4. لا تضع أسرار Cloudflare أو كلمات المرور أو رموز الجلسات في المستودع.
5. ملفات الخادم القديمة في جذر المستودع تاريخية؛ لا تُنشر ولا تُستخدم لتشغيل الأكاديمية.
