# بوابة التيسير — البوابة العامة لأكاديمية الإحسان

هذه بوابةٌ **عامة مفتوحة دون حساب أو تسجيل**، وهي المسؤولة عن:

- التعريف بالأكاديمية ورسالتها وبرامجها (مسار القرآن والعلم الشرعي، الفرق والأنشطة).
- شرح طرق الانضمام الثلاثة (طالب / شيخ–معلم / زائر–محسن) مع روابط الانتقال إلى الأكاديمية.
- شرح طرق المساهمة (دعم مالي وعيني، تطوع، نشر الخير).
- استضافة الفيديوهات وعروض الطلاب المعتمدة عند نشرها رسميًا.

## الاستقلال عن أكاديمية الإحسان

- **التيسير** = هذا الموقع (مجلد `deploy/taysir/site`)، ثابت بالكامل (HTML/CSS فقط)، لا يجمع أي بيانات شخصية، ولا يحتوي على أي سجلات أو حسابات.
- **أكاديمية الإحسان** = التطبيق الداخلي في `deploy/cloudflare/` (نفس النشر الحالي https://a-ihsan.pages.dev)، للمسجلين المعتمدين فقط، ومستبعد بالكامل من فهرسة محركات البحث (`noindex` في `_headers` + `robots.txt` + `<meta name="robots">`).
- الانتقال التيسير ← الأكاديمية يتم عبر روابط واضحة في الرأس والأقسام (أزرار «الدخول إلى الأكاديمية» و«أنشئ حساب …» التي تشير إلى `https://a-ihsan.pages.dev/#signup=<student|visitor|teacher>`)، والأكاديمية تشير بدورها إلى التيسير من صفحة الدخول وشاشة الزائر.
- **لا تدمج المنصتين ولا تكرر وظائفهما:** كل ما يخص الحسابات والطلاب والبرامج القرآنية والنقاط والبطاقات والمتجر يبقى داخل الأكاديمية حصرًا.

## النشر (Cloudflare Pages)

التيسير موقعٌ ثابت يُنشر كمشروع Pages مستقل (مثلًا `at-taysir` → `https://a-taysir.pages.dev`):

```bash
npx wrangler pages deploy site --project-name=at-taysir
```

بعد أول نشر: حدّث `TAYSIR_URL` في `deploy/cloudflare/site/app.js` (رابطان: شاشة الدخول و home للزائر) إن اختلف النطاق، ثم أعد بناء الأكاديمية (`npm run prepare:assets` داخل `deploy/cloudflare`).

ملاحظة: النشر غير منفّذ من هذه النسخة؛ يلزم حساب Cloudflare وصلاحية إنشاء مشروع Pages، وهو قرار صاحب المشروع.

## الفهرسة

- `robots.txt` يسمح للجميع + `Sitemap: https://a-taysir.pages.dev/sitemap.xml`.
- `index.html` فيه canonical و OG/Twitter و JSON-LD (EducationalOrganization + WebSite) و `robots: index,follow,max-image-preview:large`.
- لا توجد أي بيانات خاصة في هذه البوابة، فيُسمح بفهرستها بأمان.

## لا توجد حسابات أو نماذج

التيسير لا تحتوي على أي نموذج ولا لقطة بيانات ولا كوكيز؛ كل طلبات الانضمام والحسابات تتم داخل الأكاديمية وفق صلاحياتها المعتمدة (الاعتماد عند الشيخ/المسؤول المختص فقط).
