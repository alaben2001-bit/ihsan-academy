# أكاديمية الإحسان في بناء الإنسان

## المصدر المعتمد

- **الاستضافة المعتمدة:** Cloudflare Pages + Pages Functions + D1.
- **الرابط الرئيسي:** https://ihsan-academy.pages.dev/
- **نسخة الطلاب:** https://ihsan-academy-students-preview.pages.dev/
- **فرع النشر:** `migration/cloudflare-student-platform`.
- **مسار التطبيق المعتمد:** `deploy/cloudflare/`.

> لا تعتمد ملفات الجذر الخاصة بخادم Node.js القديم أو قواعد PostgreSQL بوصفها نسخة الإنتاج الحالية. أُبقيت ملفات الترحيل القديمة ومصادرها لأغراض الرجوع واستعادة البيانات التاريخية فقط. لا تنقل البيانات ولا تحذف قاعدة D1 أثناء التنظيف.

## خريطة الملفات

| المسار | المسؤولية |
|---|---|
| `deploy/cloudflare/src/index.js` | واجهة API والمصادقة والصلاحيات والتخزين في D1 |
| `deploy/cloudflare/site/app.js` | واجهة المنصة والتنقل والوظائف الأمامية |
| `deploy/cloudflare/site/style.css` | التصميم المتجاوب والوضعان الفاتح والداكن |
| `deploy/cloudflare/site/index.html` | نقطة دخول الصفحة والبيانات الوصفية |
| `deploy/cloudflare/site/startup.js` | تهيئة الواجهة المبكرة |
| `deploy/cloudflare/site/service-worker.js` | التخزين المؤقت وتثبيت PWA |
| `deploy/cloudflare/site/_headers` | ترويسات الأمان وسياسة المحتوى |
| `deploy/cloudflare/migrations/` | ترحيلات D1؛ لا تغيّر أسماء الترحيلات المطبّقة |
| `deploy/cloudflare/scripts/security-check.mjs` | اختبارات الحماية والانحدار الساكنة |
| `deploy/cloudflare/scripts/prepare-assets.mjs` | تجهيز ملفات النشر إلى `public/` |
| `deploy/cloudflare/README.md` | تعليمات التشغيل والنشر والتحذيرات |
| `deploy/cloudflare/ROADMAP-AND-AUDIT.md` | النواقص المعروفة وخطة القبول |

## الفحص والبناء

من مجلد `deploy/cloudflare`:

```bash
npm install
npm run check
npm run prepare:assets
npx wrangler deploy --dry-run
```

نجاح هذه الأوامر يثبت اجتياز الفحوصات المدرجة فقط؛ ولا يغني عن تجربة تسجيل الدخول وتغيير كلمة المرور والصلاحيات لكل دور على المنصة المنشورة.

## قواعد المحافظة على البيانات

1. لا تشغّل إعداد الحسابات الجماعي لمجرد الاختبار؛ فقد يعيد ضبط كلمات المرور للحسابات الموجودة ضمن القائمة.
2. لا تعدّل قاعدة D1 مباشرةً أثناء تنظيف الشيفرة.
3. لا تغيّر أسماء ملفات الترحيلات بعد تطبيقها؛ أضف ترحيلًا جديدًا لأي تعديل في المخطط.
4. احتفظ بنسخة احتياطية خاصة، واختبر الاستعادة على قاعدة اختبار قبل أي عملية نقل.
5. لا تضع كلمات المرور أو أسرار Cloudflare أو ملفات بيانات الدخول في Git.
6. حافظ على توافق إصدار الأصول في `index.html` وذاكرة `service-worker.js` عند تغيير ملفات الواجهة.

## حدود التحقق

الفحوصات الحالية تتضمن تحليل الصياغة واختبارات رجوع ساكنة. يجب استكمال اختبارات القبول التفاعلية المنفصلة للمدير والمعلم والمشرف والطالب، بما فيها عزل الأفواج، وتغيير كلمة المرور الأول، والحضور، ومتابعة القرآن، والواجبات، والنسخ والاستعادة.
