# أكاديمية الإحسان في بناء الإنسان

## المصدر المعتمد

- **الاستضافة المعتمدة:** Cloudflare Pages + Pages Functions + D1.
- **الرابط الرئيسي للأكاديمية:** https://a-ihsan.pages.dev/
- **بوابة التيسير العامة (غير منشورة بعد):** `deploy/taysir/` — مقترحة على `https://a-taysir.pages.dev/`.
- **فرع النشر:** `migration/cloudflare-student-platform`.
- **مسار التطبيق المعتمد:** `deploy/cloudflare/`.

> لا تعتمد ملفات الجذر القديمة الخاصة بالتشغيل المحلي وقواعد البيانات السابقة بوصفها نسخة الإنتاج الحالية. أُبقيت ملفات الترحيل القديمة ومصادرها لأغراض الرجوع واستعادة البيانات التاريخية فقط. لا تنقل البيانات ولا تحذف قاعدة D1 أثناء التنظيف.

## بوابة التيسير والأكاديمية — المنصتان المنفصلتان

- **التيسير** = البوابة العامة للتعريف: الرسالة والبرامج وطرق الانضمام والمساهمة، مفتوحة دون حساب، ويُسمح لمحركات البحث بفهرستها (robots مفتوح + sitemap + JSON-LD).
- **أكاديمية الإحسان** = المنصة الداخلية للمسجلين المعتمدين (حسابات، برامج قرآنية، حضور، نقاط، بطاقات، متجر)؛ كل صفحاتها مستبعدة من الفهرسة (`X-Robots-Tag: noindex` + `robots.txt` بـ `Disallow: /` + `sitemap` فارغة).
- الانتقال التيسير ← الأكاديمية عبر روابط «الدخول/إنشاء حساب» في التيسير؛ والأكاديمية تشير إلى التيسير من صفحة الدخول وشاشة الزائر.
- النشر: الأكاديمية عبر `deploy/cloudflare` نشرًا معتادًا (بعد ترحيل `0009_signup_join_requests.sql` على النسخة الاحتياطية الإنتاجية وبإذن صريح). التيسير مشروع Pages مستقل (`at-taysir` مقترح) — النشر لم يُنفَّذ بعد.

## الفحص والبناء

من مجلد `deploy/cloudflare`:

```bash
npm install
npm run check
npm run prepare:assets
npx wrangler deploy --dry-run
```

نجاح هذه الأوامر يثبت اجتياز الفحوصات المدرجة فقط؛ ولا يغني عن تجربة تسجيل الدخول وتغيير كلمة المرور والصلاحيات لكل دور على المنصة المنشورة.

## قواعد المحافظة على البيانات

1. لا تشغّل إعداد الحسابات الجماعي لمجرد الاختبار؛ فقد يعيد ضبط كلمات المرور للحسابات الموجودة ضمن القائمة.
2. لا تعدّل قاعدة D1 مباشرةً أثناء تنظيف الشيفرة.
3. لا تغيّر أسماء ملفات الترحيلات بعد تطبيقها؛ أضف ترحيلًا جديدًا لأي تعديل في المخطط.
4. احتفظ بنسخة احتياطية خاصة، واختبر الاستعادة على قاعدة اختبار قبل أي عملية نقل.
5. لا تضع كلمات المرور أو أسرار Cloudflare أو ملفات بيانات الدخول في Git.
6. حافظ على توافق إصدار الأصول في `index.html` وذاكرة `service-worker.js` عند تغيير ملفات الواجهة.

## حدود التحقق

الفحوصات الحالية تتضمن تحليل الصياغة واختبارات رجوع ساكنة. يجب استكمال اختبارات القبول التفاعلية المنفصلة للمدير والمعلم والمشرف والطالب، بما فيها عزل الأفواج، وتغيير كلمة المرور الأول، والحضور، ومتابعة القرآن، والواجبات، والنسخ والاستعادة.
