# أكاديمية الإحسان في بناء الإنسان

> **تنبيه مهم:** هذا الفرع (main) يحتوي على نسخة تاريخية من المشروع، وليس مصدر النشر الحالي. لا تضف إصلاحات المنصة الحالية هنا.

## المصدر المعتمد حاليًا

- **الموقع:** https://a-ihsan.pages.dev/
- **مستودع GitHub:** https://github.com/alaben2001-bit/ihsan-academy
- **فرع التطوير والنشر:** migration/cloudflare-student-platform
- **مجلد التطبيق المنشور:** deploy/cloudflare/
- **Cloudflare Pages:** المشروع a-ihsan
- **البناء:** npm install && npm run prepare:assets
- **مجلد الإخراج:** public

انتقل إلى الفرع المعتمد قبل تعديل الواجهة أو الخادم أو إعدادات النشر. المرجع التفصيلي للملفات والفحوصات وقواعد حماية البيانات موجود في ملف README.md داخل الفرع المعتمد.

## المحافظة على البيانات

- لا تحذف قواعد البيانات أو سجلات الطلبة أثناء تنظيف المستودع.
- لا تنقل ملفات البيانات القديمة إلى النسخة الحالية تلقائيًا.
- لا تضع كلمات المرور أو مفاتيح API أو أسرار Cloudflare في Git.
- احتفظ بهذا الفرع للرجوع التاريخي فقط إلى أن يكتمل تدقيق الترحيل.
