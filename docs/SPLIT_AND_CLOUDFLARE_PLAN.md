# سجل تاريخي مؤرشف: خطة الانتقال إلى Cloudflare

هذه الوثيقة تحفظ سياق مرحلة التخطيط السابقة في أكتوبر 2026. لم تعد خطة تشغيل أو تعليمات نشر، ولا ينبغي اتباع أسماء الخدمات أو الروابط أو خيارات الاستضافة الواردة في نسختها التاريخية.

**الحالة الحالية:** تعمل الأكاديمية على Cloudflare Pages وD1 من `deploy/cloudflare/`، وتعمل بوابة التيسير العامة بصورة مستقلة من `site-taysir/`. راجع `README.md` و`deploy/cloudflare/README.md` للحالة الحالية.

- لا تستخدم استضافة Render أو روابطها القديمة.
- لا تنفّذ نقلًا أو حذفًا لقاعدة البيانات اعتمادًا على هذه الوثيقة.
- لا تحذف مشاريع Cloudflare التاريخية قبل التحقق من نطاقاتها وتكاملاتها؛ ولا تحذف أي بيانات طلاب.
- سجل Git يحفظ النسخ التاريخية عند الحاجة للمراجعة، أما مصدر الإنتاج فهو الفرع المحدد في README.

تم إبقاء هذا الملف بعنوانه لتجنب كسر الروابط الداخلية، مع تعطيل كل التعليمات التشغيلية القديمة.
