# خطة جاهزية الإطلاق — أكاديمية الإحسان

**الهدف:** إطلاق تدريجي مستقر يحافظ على بيانات الطلاب والحسابات، مع واجهة هاتف قابلة للتثبيت، ودخول واضح، وقابلية العثور على الصفحات العامة عبر محركات البحث.

## المرحلة 1 — أساس الهوية والدخول
- [x] تخزين بصمة كلمة المرور في قاعدة البيانات بدل النص الأصلي (PBKDF2-SHA-256 في نسخة D1).
- [x] توضيح حفظ كلمة المرور في مدير المتصفح، منفصلًا عن جلسة الموقع.
- [x] جعل «تذكّر دخولي» اختيارًا واضحًا: الجلسة العادية تستخدم `sessionStorage`، والجلسة التي اختار المستخدم تذكرها تستخدم `localStorage` مع انتهاء مخطط بعد 30 يومًا.
- [x] إضافة واجهة Google Identity Services ومسار API يتحقق على الخادم من التوقيع والمطالبات المهمة.
- [x] منع إنشاء مستخدم أو منحه دورًا من مجرد مصادقة Google.
- [ ] **مطلوب من مالك المشروع:** إنشاء Web OAuth Client ID في Google Cloud وإضافة `GOOGLE_CLIENT_ID` إلى إعدادات Cloudflare Pages للمشروع/المشاريع المطلوبة.
- [ ] إجراء اختبارات حية للدخول، ورفض الحساب غير الموجود، والخروج وانتهاء الجلسة، بعد إضافة المعرف.

## المرحلة 2 — تطبيق الهاتف (PWA)
- [x] manifest بعرض مستقل وأيقونات مربعة 192/512.
- [x] زر تثبيت لا يختفي على الهاتف وإرشادات خاصة بـ Android وiPhone والمتصفحات المكتبية.
- [x] Service Worker يخزن shell وأيقونات وصفحات عامة، مع إصدار cache جديد.
- [ ] اختبار التثبيت على جهاز Android حقيقي وiPhone حقيقي، والعودة من الخلفية، والتحديث وإزالة التطبيق وإعادة تثبيته.
- [ ] مراجعة السلوك دون إنترنت: يجب ألا تُعرض بيانات قديمة أو خاصة على جهاز مشترك، ويجب أن يتوقف الوصول المحمي عندما تنتهي الجلسة.

## المرحلة 3 — صفحات Google العامة والفهرسة
- [x] إزالة `noindex,nofollow` من الصفحة العامة وتوجيه canonical إلى عنوان الأكاديمية الرئيسي.
- [x] إضافة بيانات منظمة WebSite ووصف وعناوين اجتماعية.
- [x] إنشاء صفحة تعريف عامة `/about.html` وصفحة خصوصية `/privacy.html`.
- [x] إنشاء `/robots.txt` و`/sitemap.xml` وقائمة نشرها في عملية البناء.
- [ ] تحديد النطاق النهائي المملوك وربطه قبل الإطلاق الرسمي إن كان المطلوب نطاقًا خاصًا.
- [ ] تأكيد أن الملفات المنشورة ترجع HTTP 200، وأن الروابط canonical صحيحة على النسختين.
- [ ] في Google Search Console: إثبات ملكية الموقع الصحيح، إرسال خريطة الموقع، استخدام URL Inspection للصفحات العامة، ومعالجة الأخطاء/الصفحات المستبعدة. النشر أو الإرسال لا يضمن الفهرسة الفورية.
- [ ] عدم فهرسة لوحات الإدارة أو أي معلومات تخص الطلاب؛ ملف robots وحده ليس نظام صلاحيات، ولذلك يجب أن تبقى API محمية بالخادم.

## المرحلة 4 — الخصوصية والأمان
- [ ] اختبار صلاحيات كل دور على كل طلب API بما في ذلك التلاعب بمعرّفات الطلاب والأفواج والمدارس.
- [ ] اختبار الجلسات وتسجيل الخروج وتغيير كلمة المرور والمحاولات الفاشلة والحدود.
- [ ] التأكد من إزالة `BOOTSTRAP_SECRET` من إعدادات الإنتاج بعد إعداد أول مدير.
- [ ] أخذ نسخة احتياطية منفصلة، ثم استعادتها في قاعدة اختبار والتحقق من عدد السجلات وعلاقاتها دون تعديل قاعدة الإنتاج.
- [ ] مراجعة ترويسات الأمن وCSP بعد تفعيل Google، وألا توجد أسرار في الواجهة أو المستودع أو سجلات الأخطاء.
- [ ] إكمال وسيلة تواصل فعلية في سياسة الخصوصية ومراجعة كيفية معالجة بيانات الأطفال والطلاب.

## المرحلة 5 — قبول الوظائف التعليمية والإدارية
- [ ] فحص رحلة كاملة للمدير، ومعلم، ومشرف، وطالب على الحاسوب والهاتف.
- [ ] فحص الحضور، ومتابعة القرآن، والاختبارات والدرجات والتقارير والصلاحيات وحدود المدرسة/الفوج.
- [ ] تحديد الميزات غير المنفذة في نسخة Cloudflare الحالية قبل الإعلان: هذه نسخة مبسطة وليست نقلًا مطابقًا لكل ميزات إصدار Node/PostgreSQL الأقدم؛ راجع `deploy/cloudflare/README.md`.
- [ ] تجربة الاستخدام مع مستخدم جديد: يفتح الصفحة، يعرف كيف يدخل، ينجز مهمة، ويرى تقدمه دون مساعدة.

## المرحلة 6 — الإطلاق والمراقبة
- [ ] نشر تجريبي على حسابات اختبار قبل مشاركة الرابط العام.
- [ ] الاحتفاظ بنسخة قابلة للرجوع وعدم حذف الاستضافة القديمة أو النسخ الأصلية قبل اختبار الاستعادة والمقارنة.
- [ ] مراقبة صحة API، واستهلاك Cloudflare، وأخطاء Console، ومشكلات الدخول والتثبيت.
- [ ] بعد اجتياز البوابات السابقة فقط: الإعلان العام، وتحديث الروابط التعريفية، ومتابعة Search Console بعد عدة أيام.

## الحالة الحالية الصريحة
- **موجود في الكود:** أساس PWA، واجهة Google Sign-In، تحقق Google خادميًا للحسابات الموجودة، تخزين بصمات كلمات المرور، صفحات تعريف/خصوصية، robots/sitemap.
- **يتطلب إعدادًا خارج الكود:** `GOOGLE_CLIENT_ID` من Google Cloud، وربطه في إعدادات Cloudflare Pages، واختيار النطاق النهائي إن لزم.
- **غير مثبت بعد:** نجاح Google Sign-In الحقيقي، نجاح التثبيت على أجهزة فعلية، قراءة sitemap/فهرسة الصفحات في Google، واختبارات الاستعادة والصلاحيات الكاملة. لا يُعلن إطلاق إنتاجي كامل قبل تسجيل نجاح هذه الاختبارات.
