# قائمة ما قبل الإنتاج

## قاعدة البيانات
- تشغيل قاعدة SQL/SQLite الإنتاجية بعد مراجعة المخطط والهجرة.
- أخذ نسخة احتياطية واختبار الاستعادة قبل فتح الخدمة.
- تفعيل مراقبة سلامة قاعدة البيانات.

## الشبكة والهوية
- تشغيل HTTPS خلف reverse proxy موثوق.
- ضبط الجلسات والـTTL من البيئة وعدم استخدام حسابات الاختبار.
- تفعيل مزود هوية/إدارة حسابات حقيقي عند فتح الأكاديمية للعامة.

## الأمن
- الاحتفاظ بالصلاحيات على الخادم وعدم الوثوق بالواجهة.
- تفعيل حدود الطلبات ومراقبة سجلات الدخول.
- تخزين الملفات التعليمية في مساحة خاصة وعدم جعل مجلد البيانات عامًا.
- مراجعة سياسة CORS/الوكيل العكسي وفق البنية النهائية.

## المحتوى الشرعي
- مراجعة الشيخ لكل درس موسوم draft أو needs_review قبل نشره.
- تثبيت مرجع الآية والحديث ومصدره في المحتوى المنشور.
- عدم إضافة حديث أو قصة بلا مصدر واضح.

## التشغيل
- تشغيل `npm test`.
- تشغيل backup ثم restore على نسخة اختبارية.
- اختبار حساب إداري ومعلم وطالب وولي أمر في بيئة شبيهة بالإنتاج.
- مراجعة السجل audit_log بعد الاختبارات.
