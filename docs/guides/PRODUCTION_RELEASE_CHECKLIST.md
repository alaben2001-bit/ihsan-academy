# قائمة ما قبل الإطلاق — أكاديمية الإحسان

الحالة: قائمة عمل، وليست شهادة نجاح نهائي. تتعلق هذه النسخة بتطبيق Cloudflare Pages + Functions + D1 في الفرع `migration/cloudflare-student-platform`.

## المنجز في التحديث الحالي
- [x] إضافة أساس دخول Google Identity Services مع تحقق الخادم من التوقيع وissuer وaudience ووقت الانتهاء وnonce والبريد المتحقق.
- [x] ربط Google بالحساب النشط الموجود فقط عند تطابق البريد؛ لا إنشاء حسابات تلقائية ولا منح أدوار.
- [x] إضافة إرشادات تثبيت الهاتف، وأيقونات تطبيق بأحجام 192 و512، وتحديث مخبأ Service Worker.
- [x] توضيح الفرق بين حفظ كلمة المرور في مدير المتصفح وتذكّر جلسة الدخول.
- [x] تقييد تخزين رمز الجلسة الدائم بخيار «تذكّر دخولي»، واستخدام sessionStorage عند عدم اختياره.
- [x] إضافة صفحة تعريف عامة وسياسة خصوصية وملفي robots.txt وsitemap.xml.
- [x] السماح بالزحف من robots meta وإصلاح canonical إلى الموقع الرئيسي وإضافة structured data.
- [x] السماح بالاتصالات المطلوبة لـ Google Identity Services في CSP دون فتح script-src لجميع المصادر.

## بوابات إلزامية قبل الإطلاق العام
- [ ] حسم النطاق النهائي وربطه بـ Cloudflare. لا تزال مشاريع Pages دون نطاق مخصص في آخر تحقق.
- [ ] إنشاء OAuth Client ID من نوع Web في Google Cloud، ثم إضافة أصل الموقع الفعلي في Authorized JavaScript origins وضبط بيانات الموافقة وروابط السياسة.
- [ ] إضافة `GOOGLE_CLIENT_ID` إلى إعدادات Pages لكل مشروع وبيئة يراد فيها تسجيل الدخول، ثم إعادة النشر.
- [ ] اختبار دخول Google لحساب نشط ببريد مطابق، ورفض بريد غير موجود، ورفض token/nonce مزوّر أو منتهي، والخروج وانتهاء الجلسة. لم تُنفذ اختبارات OAuth حية لأن Client ID غير مهيأ.
- [ ] اختبار زر تثبيت PWA على Android/Chrome وiPhone/Safari والكمبيوتر، ثم فتح التطبيق المثبت والتحقق من التنقل والرجوع.
- [ ] التأكد من عودة HTTP 200 للصفحات `/`, `/about`, `/privacy`, `/robots.txt`, `/sitemap.xml`, `/manifest.json`, `/service-worker.js`.
- [ ] في Google Search Console: التحقق من ملكية الأصل النهائي، وإرسال `https://a-ihsan.pages.dev/sitemap.xml` أو نسخة النطاق النهائي، ثم فحص URLs وطلب الفهرسة. إرسال الطلب لا يضمن قبول كل صفحة أو ظهورها فورًا.
- [ ] أخذ نسخة احتياطية مستقلة من بيانات الإنتاج واختبار الاستعادة في بيئة منفصلة قبل دعوة الطلاب.
- [ ] اختبار كل دور على كل API وعلى الهاتف والكمبيوتر، وخاصة منع الوصول خارج نطاق المدرسة/الفوج.
- [ ] بعد إنشاء المدير الأول، إزالة `BOOTSTRAP_SECRET` من بيئة الإنتاج وإعادة النشر، ثم اختبار أن إعداد المدير لم يعد متاحًا للعامة.
- [ ] مراجعة جلسات المستخدم وتحديد معدل الدخول وخصائص الأمان وCSP بعد Google واختبار أن الأخطاء لا تسرب أسرارًا.
- [ ] استكمال بيانات تواصل حقيقية في سياسة الخصوصية ومراجعة متطلبات بيانات القاصرين محليًا.
- [ ] إجراء تجربة قبول فعلية مع مدير ومعلم وطالب قبل الإعلان العام.

## حقائق مؤكدة عن كلمات المرور
- قاعدة D1 تحفظ `password_hash` باستخدام PBKDF2-SHA-256، ولا تحفظ كلمة المرور الأصلية كنص واضح.
- بعد نجاح الدخول، قد يظهر للمتصفح خيار حفظ كلمة المرور في مدير كلمات المرور؛ إذا وافق المستخدم تكون في Google Password Manager/مدير المتصفح لا في قاعدة الأكاديمية.
- «تذكّر دخولي» مختلف عن حفظ كلمة المرور: يخزن رمز جلسة في localStorage حتى 30 يومًا عند اختياره، وإلا في sessionStorage لجلسة المتصفح فقط.
- لا يمكن استرجاع كلمة المرور الأصلية من بصمتها؛ إذا نسيها المستخدم فيجب توفير إجراء تغيير/إعادة ضبط موثوق.

## عناصر غير متحققة بعد
- Google sign-in الفعلي: يعتمد على `GOOGLE_CLIENT_ID` الذي لم يكن مضافًا إلى Pages في آخر فحص.
- ملكية Search Console وقراءة Sitemap وفهرسة Google: لم يتم تأكيدها عبر Search Console ضمن هذا العمل.
- الاختبارات الحية للنسخ والاستعادة، وتثبيت Android/iOS، وجميع نطاقات الصلاحيات: لا تعتبر ناجحة قبل تنفيذها وتسجيل نتائجها.
