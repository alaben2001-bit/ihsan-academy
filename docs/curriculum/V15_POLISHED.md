# V17 — النسخة المحسّنة

هذه النسخة مبنية مباشرة فوق مشروع V17 الأصلي، وليست إعادة بناء من الصفر.

## التحسينات
- لوحة رئيسية أكثر وضوحًا وجمالًا.
- واجهة Hero جديدة مع هوية الأكاديمية.
- رسالة يومية تربوية تختلف حسب دور المستخدم.
- تحسين بطاقات الإحصاءات والمنشورات والأزرار.
- تحسين تجربة الهاتف والشاشات الصغيرة.
- الحفاظ على RTL والصلاحيات والـAPI والبيانات.
- لا توجد مكتبات خارجية جديدة.

## التشغيل
```bash
npm start
```
ثم افتح:
`http://localhost:3000`
