# V15 — أدوات المعلم والتقرير التلقائي

## مسارات API الجديدة
| المسار | الغرض | من يستطيع |
|---|---|---|
| GET /api/attendance/sheet?group_id&date | كشف حضور الفوج ليوم محدد | معلم الفوج / الإدارة |
| POST /api/attendance/bulk | حفظ حضور الفوج كاملًا | معلم الفوج / الإدارة |
| POST /api/tests | إنشاء اختبار | معلم الفوج / الإدارة |
| GET /api/tests/:id/grades | جدول درجات الاختبار | معلم الفوج / الإدارة |
| POST /api/tests/:id/grades | حفظ الدرجات دفعة واحدة | معلم الفوج / الإدارة |
| GET /api/students/:id/file?month=YYYY-MM | ملف الطالب الكامل | حسب النطاق |
| GET /api/reports/monthly?student_id&month | تقرير شهري محسوب مباشرة | حسب النطاق |
| POST /api/reports/generate | حفظ التقرير في السجل | معلم الطالب / الإدارة |

مسارات V14 باقية وتعمل (مع تشديد التحقق): `/api/attendance`, `/api/grades`, `/api/teacher-notes` وغيرها.

## قواعد التقرير الشهري
- نسبة الحضور = (الحاضر + المتأخر × 0.75) ÷ (الحاضر + المتأخر + الغائب). الغياب بعذر لا يدخل في المقام.
- متوسط الدرجات = متوسط نسب الاختبارات المرصودة في الشهر.
- إتقان الحفظ وتقدم الأهداف: الحالة الحالية.
- المقارنة تكون مع الشهر السابق للطالب نفسه فقط، ولا يقارن النظام الطلاب ببعضهم.
- الملخص لا يتضمن نص ملاحظات المعلمين؛ تُعرض الملاحظات المشاركة فقط في ورقة التقرير.

## مبدأ الملاحظات
الملاحظة التربوية مختصرة ونافعة ومحترمة. تبقى للمعلمين فقط ما لم يختر المعلم مشاركتها مع الطالب وولي الأمر.
