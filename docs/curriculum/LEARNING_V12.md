# V12 — المتابعة التعليمية

## المبدأ
الهدف ليس جمع الأرقام، بل بناء الاستمرار والإتقان.

### الحفظ
لكل عنصر محفوظ:
- الحالة
- نسبة الإتقان
- آخر مراجعة
- موعد المراجعة القادمة

### المراجعة المتباعدة
الفواصل الأولية في النظام:
1، 3، 7، 14، 30 يومًا.

هذه ليست قاعدة جامدة؛ المعلم يمكنه تعديلها حسب مستوى الطالب.

### الأهداف
كل طالب يمكن أن تكون له أهداف:
- عادة
- إتقان
- قراءة
- مهارة

مع نسبة تقدم واضحة.

### الاختبارات
يوجد الآن هيكل:
- الاختبار
- المجموعة
- التاريخ
- الدرجة القصوى
- درجة الطالب
- ملاحظة المعلم

### المرحلة القادمة
V13:
- تقارير شهرية وسنوية تلقائية.
- سجل حضور تفصيلي.
- تقييم المعلم.
- ربط ولي الأمر بالنتائج.
- لوحة مقارنة الطالب بنفسه عبر الزمن، لا مقارنة الطلاب ببعضهم.
