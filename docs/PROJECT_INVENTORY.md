# جرد أولي لمشروع أكاديمية الإحسان

تاريخ الفحص: 2026-10-09  
الفرع: `docs/stage-0-audit-rebased`  
المصدر: ملفات المستودع المتاحة على الفرع `main`. هذا جرد أولي موثق، وليس ادعاءً بفحص كل ملف أو تشغيل التطبيق.

## ملفات تمت معاينتها مباشرة

| المسار | الملاحظة |
|---|---|
| `README.md` | يوثق الوظائف والاختبارات ومتطلبات الإغلاق، لكنه يذكر V49 بينما `package.json` يذكر V58. |
| `package.json` | تطبيق Node.js؛ أوامر تشغيل واختبار وأدوات تخزين وترحيل ونسخ احتياطي لـ PostgreSQL وSQLite/JSON. |
| `server/server.js` | خادم HTTP، طبقة تخزين، جلسات، تجزئة كلمات المرور، وحدود صلاحيات وتسجيل تدقيق. رأس الملف ما زال يصف V32 والتخزين المحلي JSON؛ يجب تحديثه بعد إثبات البنية الفعلية. |
| `tests/smoke.js` | اختبارات حارسة للحضور الأسبوعي، طلبات الإشراف، إنشاء الحسابات، والتخزين؛ لا تكفي وحدها لاختبار قبول شامل. |
| `Dockerfile` | Node 22، تثبيت الإنتاج، تشغيل `npm test` أثناء البناء، ثم تشغيل الخادم بحساب غير root. |
| `render.yaml` | يعرّف خدمتي ويب وPostgreSQL على Render؛ يجب مراجعة ازدواجية الخدمتين وربط قاعدة البيانات الفعلية قبل أي تعديل. |

## مجالات المشروع الظاهرة من المصدر

- واجهة عربية RTL وملفات ثابتة ضمن `assets/`.
- خادم Node.js وخدمات/مستودعات أساسية ضمن `server/`.
- تخزين قابل للتبديل، ومخطط/ترحيلات PostgreSQL.
- اختبارات دخانية ومحتوى تعليمي.
- وظائف الطلاب والأفواج والحضور والدرجات والأهداف والمتون والقرآن والفرق والمشرفين.

## مسائل يجب حسمها قبل تعديل الشيفرة

1. استخراج شجرة المستودع كاملة، ثم مراجعة الوحدات والمسارات والملفات الحساسة.
2. تحديد مصدر الحقيقة لإصدار التطبيق؛ لا تعتمد أرقام الإصدارات في العناوين وحدها.
3. التحقق من إعداد التخزين الفعلي في الخدمة الحية، لا من ملفات الإعداد فقط.
4. تحديد قاعدة البيانات التي تحتوي البيانات الأصلية، والتحقق من عدد السجلات دون عرض بيانات شخصية.
5. تشغيل الاختبارات في بيئة مضبوطة، ثم اختبار قبول حي قبل أي ترحيل أو حذف.

## سياسة التغيير

- لا حذف أو إعادة تهيئة لقاعدة بيانات قائمة.
- لا نشر مباشر لتغيير كبير قبل اختباره في فرع منفصل.
- لا كلمات مرور أو روابط اتصال سرية في Git أو سجلات العمل.
- أي إنجاز يوسم «متحقق» فقط بعد نتيجة قابلة للمراجعة.
