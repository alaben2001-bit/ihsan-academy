# سجل جرد تاريخي مؤرشف

هذه الوثيقة جرد قديم لملفات وبنية المشروع قبل اعتماد Cloudflare. معلوماتها الزمنية والخدمية لا تصف حالة الإنتاج الحالية، ولا تُستخدم لتحديد رابط المنصة أو تشغيل قاعدة بيانات أو خدمة قديمة.

## المصدر الحالي

- الأكاديمية الداخلية: Cloudflare Pages + Pages Functions + D1، من `deploy/cloudflare/` على فرع `migration/cloudflare-student-platform`.
- بوابة التيسير العامة: Cloudflare Pages من `site-taysir/` على فرع `feat/taysir-public-portal`.
- الحالة والاختبارات والمهام المتبقية: راجع `README.md` و`deploy/cloudflare/README.md`.

## سياسة الأرشفة

- ملفات الخادم وقواعد البيانات القديمة في الجذر محفوظة لأغراض الرجوع التاريخي فقط، وليست مصدر نشر.
- لا تستخدم إعدادات الاستضافة السابقة ولا تعِد تشغيل الخدمات القديمة.
- لا تحذف ملفات أو قواعد بيانات تاريخية قبل التحقق من النسخ الاحتياطية والاعتماد الصريح.
- لا تُدرج روابط الاستضافة السابقة في واجهات الطلاب أو وثائق التشغيل.
