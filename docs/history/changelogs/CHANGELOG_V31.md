# V31 — النواة الإنتاجية المنظمة

## ما تغير
- إنشاء `production_schema_v31.sql` كنواة SQLite منظمة بدل جدول الوثائق العام.
- فصل المجالات الأساسية إلى جداول مترابطة: المستخدمون، الأفواج، الطلاب، العضويات، تعيينات المعلمين، الحضور.
- تحويل قلب المدرسة القرآنية إلى جداول مترابطة: المستويات، الحلقات، الخطط، المراجعات، حضور الحلقة، التقييمات، الشهادات.
- الحفاظ على الحقول الخاصة/المستقبلية داخل `extra_json` بدل فقدانها أثناء الهجرة.
- إضافة مفاتيح خارجية وفهارس وقيود أساسية لمنع العلاقات المكسورة.
- إضافة هجرة ذرية قابلة للعكس من JSON إلى النواة المنظمة.
- إضافة `verify:core` للتحقق من عدد السجلات وسلامة SQLite والمفاتيح الخارجية.
- إضافة اختبارات خاصة بالنواة المنظمة.

## قرار مهم
V31 لا يحوّل الخادم إلى القراءة من النواة المنظمة بعد. الخادم يبقى على Storage Adapter الحالي، والنواة الجديدة تعمل كهدف إنتاجي مُتحقق منه (shadow target). هذا يمنع قطع النظام قبل اختبار التكافؤ والكتابة الآمنة.
