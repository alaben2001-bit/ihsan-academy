# V37 — تجربة التطبيق والوسائط

- تحسين الهوية البصرية للواجهة الرئيسية والبطاقات والأزرار والهواتف.
- تطوير مكتبة الشيخ إلى تجربة وسائط أوضح: بطاقات مرئية، تصفية حسب النوع، مشغل صوت، سرعة تشغيل 1x–2x ومؤقت استماع.
- تحسين تجربة الهاتف وإضافة نافذة تثبيت كتطبيق PWA عند دعم المتصفح.
- إضافة Service Worker لواجهة التطبيق الأساسية مع استراتيجية شبكة ثم كاش، دون تخزين استجابات API الحساسة.
- تحسين وصف مكتبة الشيخ ليكون أقرب إلى تجربة تعليمية لا مجرد مستودع ملفات.
- إصلاح نموذج تحرير الدرس في الواجهة حتى تبقى كل حقول "مجلس الدرس" داخل النموذج نفسه.
- جميع اختبارات V23–V35 ما زالت ناجحة بعد التحديث.
