# V36 — تثبيت المحتوى والتشديد الإنتاجي

- استكمل مخطط المحتوى الغني عبر محاور المنهج، بحيث لم تعد الدروس مجرد عناوين ووصف مختصر.
- أضيفت افتتاحيات تربوية، قصص/موعظة، شرح، أمثلة وأسئلة وعمل ومراجعة بحسب طبيعة كل درس.
- أضيفت حماية عامة من كثرة الطلبات لكل عنوان شبكة، مع قابلية ضبطها من البيئة.
- أضيفت رؤوس حماية HTTP أساسية.
- أصبحت مدة الجلسة وحد الطلبات قابلين للضبط من البيئة.
- لا يُعامل المحتوى الشرعي غير المراجع على أنه موثّق؛ تبقى حالة المصدر جزءًا من محتوى الدرس.
