# V32 — Repository / Service Core

## ما تغير
- إضافة `server/repositories/core.js` لعزل الوصول إلى المستخدمين والأفواج والطلاب والعضويات عن طبقة HTTP.
- إضافة `server/services/core.js` لعزل عمليات المصادقة وإنشاء/تعديل المستخدمين عن تفاصيل التخزين.
- ربط تسجيل الدخول وإدارة المستخدمين بواجهة الـRepository.
- ربط قراءة الأفواج وملخص النواة بواجهة الـRepository.
- إضافة `/api/core/summary` كفحص بسيط لتكامل طبقة النواة.
- رفع رقم الإصدار إلى 32.

## التوافق
- JSON ما زال التخزين الافتراضي.
- SQLite يبقى قابلًا للتفعيل دون تغيير واجهة الـAPI.
- لم تُحذف أي ميزة سابقة.

## الأمان
- لم تُنقل الصلاحيات إلى الـRepository؛ الصلاحيات بقيت في الخادم.
- الـRepository لا يثق ببيانات العميل ولا يحدد الدور.

## الاختبارات
- اختبارات V23–V31 السابقة بقيت ناجحة.
- إضافة اختبارات Repository/Service وتكامل الخادم.
