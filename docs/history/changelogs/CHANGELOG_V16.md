# أكاديمية بناء الإنسان — V17

## ما تم إنجازه فعليًا
- رحلة تعلم فعلية للطالب بدل الاكتفاء بعرض المنهج.
- تسجيل إكمال الدروس وإلغاء الإكمال مع حفظ التقدم.
- لوحة مواد تعرض عدد الدروس المكتملة ونسبة التقدم.
- أهداف شخصية يضيفها الطالب بنفسه.
- تحديث سريع لتقدم الهدف إلى 25/50/75/100%.
- سجل تدقيق داخلي محدود للأحداث الحساسة، ظاهر للإدارة فقط.
- تشديد الجلسات: تنظيف دوري للجلسات المنتهية وحد أقصى للجلسات النشطة.
- تشديد مصدر الطلبات API لمنع الطلبات القادمة من أصل مختلف.
- ترويسات أمنية إضافية: Permissions-Policy وCOOP وCORP.
- `/api/health` لا يكشف إعدادات البيئة أو حالة الربط السحابي.
- `start.bat` يتعامل مع حالة تشغيل المنفذ 3000 مسبقًا بدل إظهار خطأ EADDRINUSE للمستخدم.
- الحفاظ على عزل الطالب وولي الأمر والمعلم والإدارة.
- جميع الاختبارات الآلية: **110 نجح، 0 فشل**.

## ملاحظة مهمة
هذه النسخة جاهزة للاستعمال المحلي وعلى نفس الشبكة. قاعدة البيانات الحالية JSON مناسبة للتجربة والتشغيل المحلي، لكنها ليست بديلًا عن قاعدة بيانات خادمية حقيقية عند نشر الأكاديمية على الإنترنت.
