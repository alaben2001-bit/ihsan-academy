# V20 — المؤسسة التعليمية

- تحويل الواجبات والتقويم والمراسلات من واجهات داخلية غير ظاهرة إلى أقسام تشغيلية واضحة.
- قسم المدرسة القرآنية يبقى قسمًا رئيسيًا مستقلًا.
- واجبات: إنشاء، تسليم، متابعة حالة التسليم والتصحيح.
- تقويم دراسي: حصص، اختبارات، أنشطة، اجتماعات وحلقات قرآن.
- مراسلات داخلية بين حسابات الأكاديمية مع حالة القراءة.
- إدارة عليا وصلاحيات كاملة للمدير مع النسخ الاحتياطي وسجل العمليات.
- تحسين التشغيل المحلي عبر start.bat وcmd.txt.
- الحفاظ على عزل صلاحيات الخادم لكل دور.
