# V26 — الإدارة التشغيلية للهيكل والمنهج

## ما تغير
- إضافة إدارة حقيقية للأفواج من لوحة الإدارة: إنشاء، تعديل، تعطيل، وحذف آمن.
- إضافة إدارة إسناد الشيوخ إلى الأفواج مع استبدال الإسناد دفعة واحدة.
- إضافة قائمة المعلمين النشطين للإدارة.
- منع حذف فوج مرتبط بطلاب أو شيوخ أو طلبات معلقة؛ يستخدم التعطيل بدلًا من الإتلاف.
- إضافة أرشفة للمواد والدروس بدل الحذف الفيزيائي، مع إخفائها عن الطلاب.
- تشديد `/api/program` و`/api/subjects` و`/api/lessons` حتى لا تكشف العناصر المؤرشفة للمستخدمين غير الإداريين.
- إضافة واجهة إدارة الأفواج وإسناد الشيوخ داخل لوحة الإدارة.
- إضافة اختبارات خادم خاصة بـV26.

## الأمن
- جميع عمليات الإدارة الجديدة محمية بصلاحية المدير على الخادم.
- لا يمكن للمعلم تغيير إسناد الشيوخ.
- لا يمكن حذف كيان له ارتباطات تشغيلية قد تكسر السجل التاريخي.
- الأرشفة لا تزيل البيانات التاريخية.
