# أكاديمية الإحسان في بناء الإنسان — V18

## ما تم إنجازه
- مركز إدارة عليا حقيقي للمدير.
- إدارة المستخدمين: إنشاء، تعديل، تغيير الدور، تفعيل/تعطيل، إعادة تعيين كلمة المرور.
- صلاحيات الإدارة الكاملة موضحة داخل النظام.
- لوحة حالة النظام: المستخدمون، الطلاب، الأفواج، الدروس، الجلسات، حجم قاعدة البيانات ونسخة Node.
- سجل عمليات إداري مختصر.
- تنزيل نسخة احتياطية كاملة من قاعدة JSON من داخل لوحة المدير.
- منع تسجيل الدخول للحسابات المعطلة.
- عدم إرجاع كلمات المرور أو الهاشات في ردود الواجهة.
- الحفاظ على عزل الطالب وولي الأمر والمعلم كما في V17.
- تشغيل المشروع عبر `start.bat` مع معالجة مشكلة EADDRINUSE وفتح النسخة الموجودة بدل تشغيل سيرفر ثانٍ.
- إضافة `cmd.txt` بالأوامر المطلوبة:
  - `set NODE_SKIP_PLATFORM_CHECK=1`
  - `node server/server.js`
- تحسين الهوية لتصبح النسخة قابلة للتطوير كمنتج مؤسسي حقيقي.
