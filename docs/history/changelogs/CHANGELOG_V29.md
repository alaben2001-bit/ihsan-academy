# V29 — التخزين الانتقالي والنسخ الاحتياطي والترحيل

## ما تم تغييره
- إضافة `tools/backup-db.js` لإنشاء نسخة احتياطية ذرية من قاعدة JSON مع SHA-256.
- إضافة `tools/restore-db.js` لاستعادة نسخة صالحة مع إنشاء نسخة أمان قبل الاستعادة.
- إضافة `tools/export-production-sql.js` لتصدير بيانات JSON الحالية إلى طبقة SQLite/D1 انتقالية.
- إضافة `production_schema_v29.sql` الذي يعرّف طبقة تخزين انتقالية متوافقة مع جميع مجموعات البيانات الحالية.
- إضافة أوامر npm: `backup` و`restore` و`export:production`.
- تحديث الإصدار إلى V29.

## الأمان
- لا يتم استبدال قاعدة البيانات أثناء الاستعادة مباشرة؛ تُنشأ نسخة pre-restore أولًا ثم تتم كتابة الملف ذريًا.
- يتم التحقق من بنية النسخة المستعادة (`users` و`groups`) قبل قبولها.
- SHA-256 يحفظ للتحقق من سلامة النسخ والتصدير.
- لم يتم تحويل النظام تلقائيًا إلى قاعدة إنتاجية حتى لا يحدث كسر أو فقد للبيانات.
