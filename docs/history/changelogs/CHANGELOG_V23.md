# V23 — المدرسة القرآنية المتكاملة

- حلقات قرآنية مرتبطة بالأفواج والشيخ المسؤول.
- خطة حفظ لكل طالب مع موعد ومقطع وملاحظات.
- جدولة مراجعات مستقلة مع إكمالها من الطالب أو صاحب الصلاحية.
- منع الشيخ من إدارة طالب خارج نطاقه.
- منع إنشاء خطة بتاريخ منتهٍ.
- تحسين ملف الطالب القرآني وإظهار خطة الحفظ الحالية.
- استمرار التحقق من صحة نطاق الآيات والتقييمات والصلاحيات على الخادم.
- مراجعة منطقية لمسارات القرآن بدل الاكتفاء بسجل جلسات منفصل.
