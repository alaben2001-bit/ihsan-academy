# أكاديمية الإحسان في بناء الإنسان — V36

هذه النسخة تجمع ما بُني تدريجيًا من V23 إلى V36 دون حذف الميزات السابقة.

## ما أصبح موجودًا فعليًا
- إدارة المستخدمين والأدوار: الإدارة، الشيخ/المعلم، الطالب، ولي الأمر.
- عزل الصلاحيات والنطاق على الخادم مع سجل عمليات.
- الأفواج وعضويات الطلاب وإسناد المعلمين وطلبات النقل والانضمام.
- السنوات الدراسية والفصول والجدول المرتبط بها.
- المدرسة القرآنية: الحلقات، الحفظ، المراجعة، الحضور، التسميع، التقويم، التقارير والشهادات.
- المناهج الأساسية والاختيارية والدروس والبرنامج الأسبوعي/الشهري/السنوي.
- رحلة الطالب والتشخيص والتحديات والاعتذار عن الاختبارات والصراحة المجهولة.
- الاختبارات والدرجات والواجبات والتقارير الشهرية والمتابعة.
- المراسلات والتنبيهات ومكتبة الشيخ والمحتوى المجتمعي.
- قاعدة تخزين JSON للتطوير، ومسار SQLite/النواة المنظمة والهجرة والنسخ الاحتياطي والاستعادة.
- محتوى درس غني: افتتاحية، آيات، أحاديث، قصة، شرح، أمثلة، أسئلة، عمل، حفظ ومراجعة، مع حالة تحقق للمصدر.
- حماية HTTP وحدود للطلبات ومدة جلسة قابلة للضبط.

## ملاحظة شرعية
المحتوى الموسوم `verified` فقط هو الذي أُدخل له مرجع متحقق منه في هذه النسخة. أما المحتوى `draft` فيبقى مسودة تربوية تحتاج مراجعة الشيخ قبل اعتماده للنشر النهائي.

## التشغيل
```bash
npm install
npm test
npm start
```

## الإنتاج
راجع `PRODUCTION_RELEASE_CHECKLIST.md` قبل فتح الخدمة للعامة. لا تُستخدم حسابات الاختبار وكلمات مرورها في الإنتاج.
