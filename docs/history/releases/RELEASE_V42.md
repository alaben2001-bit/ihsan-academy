# أكاديمية الإحسان في بناء الإنسان — V42

## دفعة الإنتاج والأمان
- نظام migrations PostgreSQL مُدار عبر `academy_migrations` مع أمر status وتطبيق متدرج.
- migration جديدة لسجل أحداث أمني وفهارس مناسبة.
- استعادة PostgreSQL تتحقق من SHA-256 إن وُجد ملف `.sha256` بجانب النسخة.
- اختبارات أمنية فعلية لـ CSRF، Cookies، Security Headers وRate limiting.
- جميع ميزات V41 السابقة محفوظة.

## ملاحظة النشر
HTTPS الحقيقي وشهادة TLS وقاعدة PostgreSQL الفعلية لا تُنشأ داخل ملف المشروع؛ يجب ربط أسرار وبيئة الخادم الفعلية قبل النشر العام.
