# خريطة V22

## مكتمل
- طلبات الانضمام والنقل مع اعتماد المدير وإلغاء الطلب.
- تغيير العضوية المباشر للمدير.
- إسناد الطالب للفوج والمهمة عند إنشاء الحساب.
- المناهج الإضافية باختيار الطالب.
- مكتبة الشيخ: مقاطع وملفات وروابط، مشاهدة، إعجاب، تعليقات، ومشاهدون.
- الواجبات: تسليم، تسليم متأخر، وتصحيح المعلم.
- مراسلات حسب نطاق الدور.
- إشعارات شخصية لنتيجة طلبات الأفواج.
- تحقق من الروابط وحد رفع الملفات.

## المرحلة التالية
- قاعدة بيانات إنتاجية ومهاجرات.
- رفع ملفات احترافي وتخزين خارجي.
- جلسات آمنة مع CSRF وHTTPS وrate limiting موسع.
- نظام حلقات قرآنية متكامل بخطة الحفظ والمراجعة والتسميع.
- السنة الدراسية والفصول والجداول والانتقالات.
- تقارير وطباعة وشهادات ونسخ احتياطي مع استعادة.
- PWA/Android حقيقي وربط إشعارات خارجية.
